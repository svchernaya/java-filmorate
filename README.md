# Filmorate — REST API сервиса для оценки фильмов

**Коротко**: Разработала RESTful веб-приложение на Spring Boot для управления фильмами и пользователями с валидацией данных, логированием и юнит-тестированием.

## Что делала именно я

- Спроектировала и реализовала две сущности данных (Film и User) с использованием Lombok для сокращения boilerplate-кода
- Разработала два REST-контроллера (FilmController и UserController) с CRUD операциями:
  - POST для создания новых записей
  - PUT для обновления существующих
  - GET для получения всех записей
- Реализовала систему валидации с кастомным исключением ValidationException:
  - Валидация фильмов: название, описание (до 200 символов), дата релиза (не раньше 28.12.1895), продолжительность
  - Валидация пользователей: email (с символом @), логин (без пробелов), автоматическая подстановка логина при пустом имени
- Настроила логирование операций с использованием SLF4J и аннотации @Slf4j
- Написала комплексные юнит-тесты для проверки граничных случаев валидации
- Настроила Spring Boot приложение с автоматической конфигурацией
- Организовала проект по пакетам (controller, model) для соблюдения чистой архитектуры

## Инструменты

- **Фреймворк**: Spring Boot 2.7+
- **Язык**: Java 17
- **Библиотеки**:
  - Lombok (для аннотаций @Data, @Slf4j, @NonNull)
  - Spring Web (для REST контроллеров)
  - Spring Boot Test (для тестирования)
  - JUnit 5 (юнит-тестирование)
- **Архитектура**: REST API, MVC паттерн
- **Валидация**: Кастомная реализация + java.time API для работы с датами
- **Сборка**: Maven (предположительно)
- **Тестирование**: Postman для интеграционного тестирования API

## Результат

### Что получилось:
- Полнофункциональное REST API с эндпоинтами:
  - `POST /films` — добавление фильма
  - `PUT /films` — обновление фильма  
  - `GET /films` — получение всех фильмов
  - `POST /users` — создание пользователя
  - `PUT /users` — обновление пользователя
  - `GET /users` — получение всех пользователей
- Система хранения данных в памяти приложения (In-memory storage)
- Качественная валидация входных данных с понятными сообщениями об ошибках
- Логирование всех операций добавления/обновления
- Полное покрытие тестами критических сценариев валидации

### Ключевые особенности реализации:
1. **Автоматическая обработка имени пользователя**: если имя не указано, используется логин
2. **Историческая валидация дат**: проверка, что фильм не старше первого в истории кино (28.12.1895)
3. **Граничные тесты**: проверка минимально допустимых значений (200 символов описания, 1 минута продолжительности)
4. **Консистентность API**: все методы возвращают созданные/обновленные сущности
5. **Чистая архитектура**: разделение на контроллеры, модели и валидацию

### Чему научилась:
- Созданию RESTful веб-сервисов на Spring Boot
- Работе с аннотациями Spring (@RestController, @RequestMapping, @PostMapping и др.)

- Реализации кастомной валидации бизнес-правил

- Написанию юнит-тестов для контроллеров Spring
- Работе с HTTP-запросами и ответами в REST API
- Организации проекта по пакетам для соблюдения принципов чистой архитектуры
- Обработке исключений и возврату понятных сообщений об ошибках
- Тестированию API с помощью Postman
